## КОНЕЧНАЯ ЦЕЛЬ
Из идеи бренда родить полную бренд-платформу (стратегия+смысл+личность) + дизайн-систему
(токены+фундамент+компоненты+брендбук) за управляемый человеком проход, где:
- вкус выверен с человеком ДО генерации компонентов;
- ни одна стадия не строит на выдумках;
- падение/лимит сессии не теряет прогресс.

## ВХОД
- Бренд-идея/seed от человека (1+ абзац) + опц. `_intake/` (первоисточники: опросники,
  сайт, профили). Слаг бренда — транслит RU→latin из 1-й строки.
- Грилл-ответы из главного потока (см. инвариант полноты).

## ИНВАРИАНТ ПОЛНОТЫ (корневой дефект #0 — «выдумки»)
Discovery (S1) ведётся ГРИЛЛОМ в главном потоке по чек-листу:
формула спроса · 5 элементов (СПРОС/ПРОДУКТ/ПРОДАЖА/ПРИБЫЛЬ/МАСШТАБ) ·
по КАЖДОМУ сегменту ICP: проблема / цена бездействия / готовность платить ·
proof под каждый brand-claim · origin-факты.
**Ядровые поля: ГИПОТЕЗА ЗАПРЕЩЕНА.** Любое ГИПОТЕЗА в ядре → гейт STOP → возврат в
догрилл, НЕ строить. Неядровые (конкуренты, второстепенное) допускают явную метку.
Человек либо даёт факт, либо руками помечает «прими гипотезу X».

## АРХИТЕКТУРНЫЙ ПРИНЦИП: ИНВЕРСИЯ ОРКЕСТРАЦИИ
Старое: монолит-Workflow S0→S12 в фоне, человек снаружи стучится через файлы → весь
ад resume/кэш/args/висящего AskUserQuestion.
**Новое: главный поток (чат) = дирижёр-автомат.** Держит manifest, гейтит человека
нативно (AskUserQuestion долетает), зовёт Workflow ТОЛЬКО на короткие рои между гейтами.
Фон никогда не спрашивает и не резюмится длинно — висеть нечему.

## МОДЕЛЬ ДАННЫХ
```
runs/<brand-slug>/manifest.json        # машина состояний = SSOT прогона
  { stage, status: pending|done, artifact_path, gate_passed: bool,
    approvals: { ESSENCE, ARCHETYPE, TASTE, BRANDBOOK },
    locked_taste: { palette, fonts, direction } }
<brand-slug>-brand/tokens.css          # ЕДИНЫЙ SSOT токенов
<brand-slug>-brand/components/<slug>.html   # плоско; <link rel=stylesheet href=../tokens.css>
```
Идемпотентность: стадия `done` ⟺ артефакт на диске И прошёл дет-гейт. Свежий чат читает
manifest → прыгает на первую `pending`. Готовое = 0 токенов. Resume бесплатный, не через кэш.
